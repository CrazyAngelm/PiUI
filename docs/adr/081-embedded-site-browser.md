# ADR-081 · Встроенный браузер сайтов

Кнопка «Браузер» открывает отдельное окно Нано Desktop на Windows и Linux.
Адресная строка, вкладки и кнопки навигации принадлежат локальной странице
`browser.html`. Сайты отображаются в дочерних WebView. Окно создаётся по запросу,
пустая вкладка не запускает движок сайта. Ссылки из чата открываются в новой
вкладке этого окна. Вкладки, которые были открыты раньше, сохраняются.

Вкладки используют один профиль `browser-profile` в локальном каталоге данных приложения.
Путь сохраняется при обновлении. Профиль хранится локально и живёт независимо
от рабочих пространств, чатов и входа в аккаунт Нано. Сайт может установить
постоянные cookies и сам определяет срок действия сессии.

Нативный хост ограничивает вкладки адресами HTTP и HTTPS и запрещает переходы
на служебные адреса приложения. Для страницы сайта отсутствуют разрешения
Tauri и доступ к командам Нано. Локальная панель получает только свой маршрут
управления вкладками и события обновления панели. В безопасном режиме и в
удалённом интерфейсе браузер недоступен.

Для всплывающих окон и загрузок в первой версии используется системный
браузер. Он открывается по кнопке после подтверждения точного адреса
нативным диалогом. На системах без встроенного браузера этот же диалог
используется для ссылок из чата. OAuth аккаунта Нано
продолжает использовать системный браузер со своим хранилищем.
