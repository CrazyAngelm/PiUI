# Исправления удобства PiUI

Основание: [аудит](UX_AUDIT_2026-09-22_RU.md). Пользователь разрешил реализацию
22 сентября 2026. Изменения сохраняют существующие определения систем,
разрешения запуска и нативные форматы истории.

## Изменённое поведение

| Пункты аудита | Что изменено |
|---|---|
| UX-01 | Новый граф и новое расписание обозначены как черновики. Проверка и открытие имеют собственные состояния загрузки. |
| UX-02 | New, Open, Import и переход в библиотеку предлагают сохранить, отказаться от изменений или продолжить редактирование. Ошибка сохранения удерживает черновик и диалог. |
| UX-03–04 | Check system выполняет структурную проверку и проверку настроек по нативным каталогам. Правка снимает результат предыдущей проверки; окончательные разрешения проверяет host при запуске. |
| UX-05–06 | Undo/Redo восстанавливают граф со связями. Ввод в поле и перетаскивание группируются. Применение шаблона требует явного подтверждения замены всех типов связей. |
| UX-07 | Arrange учитывает фактическую высоту карточек, включая названия и ветки маршрутизатора. |
| UX-08–09 | Общий холст: Ctrl + колесо/жест сведения, средняя кнопка для перемещения, пробел + перетаскивание с фокусом на холсте, клавиши масштаба, Fit и сброс. У пустого графа нет искусственно заданного большого поля прокрутки. Второстепенные действия вынесены в раскрываемые панели. |
| UX-10–11 | Поиск нодов с фокусировкой, переходы из структурных и нативных ошибок, выбор связи с переходом к ноду. Масштаб и прокрутка сохраняются отдельно для каждой системы/запуска; навигация доступна в safe mode. |
| UX-12 | Дублирование нода и добавление независимой копии сохранённого агента из библиотеки. Новые идентификаторы; связи и разрешения создавать другие профили не переносятся. |
| UX-13 | Расширена область выбора линий; показаны все типы связей. Кнопка удаления называет источник, получателя и тип. |
| UX-14 | Поиск моделей, систем и ресурсов; фильтр выбранных ресурсов. Фильтрация не меняет сохранённую конфигурацию. |
| UX-15–18 | «Требует внимания» включает ожидание одобрения. После Run открывается подтверждённый запуск по ID. В списке есть ID и фильтр статуса. В графе выполнения используются общие средства навигации. |
| UX-19 | Прямой переход в библиотеку из сообщения о несовместимом графе и из добавления сохранённого агента. Из пустой формы расписания можно перейти к созданию системы с разрешением судьбы черновика. |
| UX-20 | Поиск по сохранённой нативной истории с переходом между совпадениями и обновлением результатов; сохранение позиции чтения отдельно для каждого диалога. |
| UX-21 | Явное чтение полного ответа из нативной истории и копирование ответа с сообщениями об успехе/ошибке. Обычная лента сохраняет экономный предварительный показ. |
| UX-22 | Обычная строка со слешем, например `/src/main.ts`, отправляется как текст. Командой считается точное имя доступной команды; подсказки команд остаются. |

| UX-24 | До сохранения видны цель расписания, первое и следующее срабатывание интервала, часовой пояс, правила пропусков и пересечений. Сохранение не включает выполнение. |

## Границы реализации

- Новый read-only маршрут `workspace_history_v1` принимает только внутренний ID
  диалога PiUI. Host проверяет зарегистрированный проект и источник истории.
  Он не запускает harness и работает в safe mode. Контракт `workspace-v15`
  и форматы Pi/Prime/Codex/Hermes не изменены.
- Полный текст восстанавливается для ответов ассистента. Вывод инструментов
  и другие предварительные представления остаются ограниченными существующим
  сканером; область поиска явно обозначена в интерфейсе. Незавершённая запись
  истории приводит к ошибке чтения, которую можно повторить.
- История редактирования графа действует в текущем редакторе. Автовосстановление
  незавершённого графа после аварии/закрытия приложения не добавлено: в аудите
  это было отдельной непроверенной гипотезой.
- Физический тачпад, экранный диктор и Linux требуют отдельной проверки.
  Синтетические события WebView не заменяют такую проверку.

## Проверки

Результаты команд и нативного прогона хранятся в
`evidence/ux-audit-20260922/`. Итог установки и контрольные суммы добавляются
после завершения сборки и проверки установленного приложения.

- TypeScript/Svelte: 0 ошибок и предупреждений. Полный прогон unit-тестов:
  224/224; после добавления проверок геометрии — 6/6 в затронутом наборе.
  Контрактные фикстуры и Clippy пройдены. Rust: 360 пройдено, 16 пропущено
  согласно условиям тестов.
- Нативный WebView2: изолированный профиль, настоящий host и Codex,
  синтетический провайдер без платных запросов. Проверки UX запускаются через
  `PIUI_E2E_UX_ONLY=1 pnpm --filter @piui/desktop test:e2e:workspace`.
- Старый полный сценарий останавливается на недоступном нативном каталоге
  Prime Agent. Это не отмечается как пройденная проверка этого адаптера.
- Сравнение с исходным коммитом показало превышение существовавшего лимита
  стартовых ресурсов уже до исправлений. Диалог, настройки и данные браузерного
  предпросмотра загружаются по необходимости; лимит проекта не повышался.
  Начальная загрузка уменьшена с 336 179 до 263 132 байт, `pnpm perf:smoke`
  проходит существующий предел 266 240 байт. Это размер ресурсов, не измерение
  скорости запуска установленной программы.
