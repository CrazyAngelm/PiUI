## 2. Что проверить в этой сборке

1. **Чат.** Новый чат → харнес → модель → reasoning. Проверить стриминг,
   одобрения, очередь и steer, Ctrl+K, Ctrl+F.
2. **Claude Code.** Нужен вход по подписке: в терминале `claude` → `/login`.
   Без входа PiUI покажет подсказку и не запустит агента. Fast выключен
   намеренно: он тратит платный extra usage.
3. **Codex 0.157.1** снова доступен.
4. **Пайплайны.**
   - Шаблон (например, «Цикл ревью») → нода Start → входные данные → Check → Run.
   - Кнопка «Ассистент»: описать задачу словами и применить предложение.
5. **Запуски.** Холст с состояниями шагов. Панель шага: результат, диалог,
   попытки. На лимите раундов: «Принять последний результат» или «Ещё раунд».
6. **Автоматизации.** «По дням» (например, будни 09:00), «Интервал», «Один раз».
   Автоматизация включается отдельно («Сохранить и включить»). Работает только
   пока PiUI открыт.
7. **Вызов модели и скрипт.** В редакторе «Добавить» → «Вызов модели» или
   «Скрипт».
   - У скрипта есть кнопка «Вставить пример»: он читает JSON из stdin и
     печатает JSON в stdout.
   - Нужен доверенный проект и установленный Node.js, Python или PowerShell.
   - В Запусках у скрипта виден вывод, поля результата и конец stderr при
     ошибке.
   - Кнопка «Проверить» в инспекторе скрипта запускает только его код с
     примером входных данных; тип ноды меняется чипом рядом с её названием.

8. **Новое в 0.2.0.**
   - Одобрения MCP в Codex приходят карточкой с полями.
   - `/run` в чате или Ctrl+K «Запустить пайплайн…».
   - Автоматизации «после события»: пайплайн завершился или изменились файлы.
   - Настройки → Фон: трей и автозапуск (по умолчанию выключены).
   - Настройки → Харнесы: статусы и ACP-агенты (Gemini CLI).
   - История Pi-сессий в меню проекта.
   - В запуске: «Закрепить результат», затем запуск с закреплёнными данными;
     «Отладить в редакторе»; архив и удаление запусков.

**Известные ограничения**
- Вызов модели через Codex не может отключить инструменты: работает только
  в read-only песочнице, UI это пишет. Pi и Claude Code запускаются без
  инструментов.
- Обновления внутри приложения выключены, пока нет ключа подписи
  (`docs/RELEASING.md`); сборка не подписана.
- В прошлой тестовой сборке 0.1.1 после закрытия диалога клики могли перестать
  работать (CSP). В 0.2.0 исправлено.

**Откат.** Копия прошлой сборки лежит в
`evidence/local-release-20260926/rollback-0.1.1-20260922/`. Старая версия может
не прочитать данные, которые уже записала новая.

## 4. Решения (приняты 2026-09-27)

Владелец делегировал решения («сам решай всё как лучше и доделывай быстрее»).

1. **Script-ноды:** остаются все три рантайма — Node, Python, PowerShell.
2. **Порядок:** P1 → P2 → P3. Работа идёт параллельно в отдельных ветках:
   - P1 и часть P2 сразу;
   - плагины после ACP-реестра, потому что реестр харнесов — их основа.
3. **Classic:** его функции переносятся в новый интерфейс сейчас. `?view=legacy`
   остаётся в 0.2.0 как запасной путь и удаляется в следующем релизе.
4. **Версия:** следующая сборка — 0.2.0.
5. **Push:** только после теста владельцем и по его явной команде.
