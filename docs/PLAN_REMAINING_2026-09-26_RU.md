## 2. Что проверить в этой сборке

1. **Чат.** Новый чат → харнес → модель → reasoning. Проверить стриминг,
   одобрения, очередь и steer, Ctrl+K, Ctrl+F.
2. **Claude Code.** Нужен вход по подписке: в терминале `claude` → `/login`.
   Без входа PiUI покажет подсказку и не запустит агента. Fast выключен
   намеренно: он тратит платный extra usage.
3. **Codex 0.157.1** снова доступен.
4. **Пайплайны.**
   - Шаблон (например, «Цикл ревью») → нода Start → входные данные → Check → Run.
   - Кнопка «Ассистент»: описать задачу словами и применить предложение.
5. **Запуски.** Холст с состояниями шагов. Панель шага: результат, диалог,
   попытки. На лимите раундов: «Принять последний результат» или «Ещё раунд».
6. **Автоматизации.** «По дням» (например, будни 09:00), «Интервал», «Один раз».
   Автоматизация включается отдельно («Сохранить и включить»). Работает только
   пока PiUI открыт.

**Известные ограничения**
- LLM- и script-нод ещё нет в интерфейсе (движок в работе, см. §3).
- MCP-инструменты Codex, которым нужно одобрение, всегда отклоняются (§3, п. 2).
- Если Claude не залогинен, первый шаг пайплайна на нём помечается «исход неизвестен».

**Откат.** Копия прошлой сборки лежит в
`evidence/local-release-20260926/rollback-0.1.1-20260922/`. Старая версия может
не прочитать данные, которые уже записала новая.

## 3. Оставшиеся работы по приоритету

Размеры: S — до дня, M — несколько дней, L — неделя и больше (темп с агентами).

### P1 — закрыть ядро видения

1. **LLM- и script-ноды (Ф4) — M.**
   - Движок пишется в ветке `feat/step-executors`: `executors.rs`, one-shot
     LLM-шаг через харнес, script-шаг с таймаутом и ограничением вывода.
   - После него UI: палитра, инспектор (промпт, модель, схема ответа; для
     скрипта — рантайм, код, таймаут), карточки нод, вид запуска, UI Lab,
     формат системы (аддитивно), скилл `piui-systems`.
   - Готово, когда цепочка «LLM → скрипт → агент» собирается мышью, проходит
     Check и исполняется. Скрипт запускается только в доверенном проекте,
     явно и без доступа WebView к shell.
2. **Одобрения MCP в Codex — S.** Показывать `mcpServer/elicitation/request`
   карточкой одобрения, а не отклонять молча.
3. **Claude Code: полировка — S.**
   - Статус входа виден в композере ещё до отправки.
   - В инспекторе ноды показаны ограничения харнеса.
   - Первый шаг без входа отказывается чисто, а не «исход неизвестен».
4. **E2E и регрессия — M.**
   - WebView2 E2E переведён на новый интерфейс.
   - Playwright по UI Lab: ключевые экраны и потоки, скриншоты.
   - CI гоняет всё это.

### P2 — платформа

5. **Универсальный ACP-адаптер + реестр дескрипторов — L.** Новый агент
   (Gemini CLI, DeepSeek Harness…) подключается одним дескриптором, без кода
   в ядре.
6. **Настройки → Харнесы — S–M.** Версии, статус, путь, подсказки входа,
   проверенный диапазон версий.
7. **Удаление classic — M–L.** Сначала перенести то, что есть только там:
   просмотр нативной истории Pi, дерево сессии, диалоги и переключатели
   расширений. Затем удалить старый код, контракты и команды.
8. **Триггеры (Ф7) — M.**

   - События: завершение пайплайна, изменения файлов.
   - Фоновый режим в трее и автозапуск — только с явным согласием.
