# Changelog

All notable changes to PiUI are documented here.

PiUI is currently a developer preview. Versions before a packaged public release may change without a stable migration promise; changes to typed host contracts remain versioned under `contracts/`.

## [Unreleased]

- Publication hygiene: MIT licensing metadata, public contribution/security policies, repository audit gate, and GitHub issue/PR templates.
- Appearance: persistent theme, density, reduced-motion, chat text-size, and conversation-width preferences.
- Cache-first session catalog and bounded transcript rendering improvements.

## [0.1.0] - Unreleased developer preview

- Tauri 2, Rust, and Svelte 5 desktop foundation.
- Read-only Pi session discovery, safe timeline/tree projections, and a rebuildable SQLite index.
- Explicit project trust, projectless personal chats, and a temporary local Pi RPC preview.
- Versioned internal contracts, extension manifest validation, fake runtime scenarios, and platform/security foundations.

Repository links and release tags will be added after the public remote is configured.
